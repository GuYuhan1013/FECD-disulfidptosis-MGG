# Analysis code: two-phase displacement of disulfidptosis programs in FECD

This repository contains the complete R pipeline for the manuscript:

> **Two-phase displacement of disulfidptosis-related transcriptional programs in Fuchs endothelial corneal dystrophy: an energy-first, cytoskeleton-late pattern**

The study is a purely computational re-analysis of public human corneal endothelial transcriptomes. No wet-lab data are included. Every number, table and figure in the manuscript can be regenerated from the public data and the scripts below.

## Requirements

- R 4.6.1
- Packages: limma 3.68.5, edgeR 4.10.1, WGCNA 1.74, dynamicTreeCut 1.63.1, impute 1.86.0, matrixStats 1.5.0, clusterProfiler 4.20.2, org.Hs.eg.db 3.23.1, GO.db 3.23.1, AnnotationDbi 1.74.0, fgsea 1.38.0, glmnet 5.2, data.table 1.18.4, ggplot2 4.0.3, pheatmap 1.0.13, ComplexHeatmap 2.28.0.
- Helper packages loaded directly: enrichplot 1.32.0, ggrepel 0.9.8, patchwork 1.3.2, reshape2 1.4.5.
- Python 3.12 or newer with pandas, NumPy, SciPy, Matplotlib and Pillow (S07 validation and Fig. S4). The archived S07 outputs were generated with Python 3.12.11; the statistics script was re-run under Python 3.13.18 and reproduced Table S2 exactly. `pyreadr` is required only when rebuilding the GSE74123 matrix from the raw annotation.
- A full `sessionInfo()` is provided in `sessionInfo.txt`.

## Data

All data are public and must be downloaded by the user:

1. **GSE142538** — 25 human corneal endothelial samples (9 controls, 6 pre-symptomatic *TCF4* expansion carriers, 6 expansion-positive FECD, 4 expansion-negative FECD). Download the 25 Cufflinks gene-level files from the GEO series supplementary files and place them in:

   `02_原始数据/01_GEO原始下载/GSE142538/`

2. **GSE112201** — independent public series used only for exploratory comparison (not as a validation cohort). Place the series matrix and platform annotation in:

   `02_原始数据/01_GEO原始下载/GSE112201/`

3. **Disulfidptosis gene set** — the 24 core genes from Liu et al. (2023; PMID 36747082). The list is hard-coded in `S02_01_disulfidptosisGene_detection.R`; no external file is required.

4. **GSE74123** — independent 4 FECD / 4 control microarray cohort used only as a direction check. The series matrix, seven refine.bio PCL files and the annotation go in `S07_independent_validation/`; see its `README.md`. Processed values for the 19 detectable genes are included, so the statistics and Fig. S4 can be reproduced without re-downloading.

The merged count matrix used for the reported analyses is generated by `S01_01` and is **not** included in this repository (it is large and fully reproducible from the public files).

Run scripts with `Rscript` from any directory; each script resolves the project root in this order: `FECD_PROJECT_ROOT` environment variable, then the script location (`../..`), then the current working directory. The project root must contain `02_原始数据/`. Run `S00_setup_directories.R` once to create the `04_分析结果/` and `05_文稿/` tree before step 1 (or set `FECD_PROJECT_ROOT` to the folder that contains them):

| Step | Script | Purpose |
|---|---|---|
| 0 | `S00_setup_directories.R` | Create the output directory tree (`04_分析结果/`, `05_文稿/`, processed-data folder) |
| 1 | `S01_01_merge_GSE142538.R` | Merge 25 Cufflinks files into a gene-level count matrix and sample table |
| 2 | `S02_01_disulfidptosisGene_detection.R` | Detect the 24-gene set; detection rate and log2CPM abundance (Fig. S1) |

## Reproducibility notes

- **Seed:** every stochastic step uses `set.seed(20261121)`, including the 300 stability-selection subsamples (seed passed explicitly inside the function).
- **Sample sets:** differential expression, network construction, enrichment and stability selection use the 9 controls and 6 expansion-positive advanced cases only (15 samples; 16,754 genes after `filterByExpr`). Axis scores use all 25 samples. Using 19 or 25 samples for differential expression gives different DEG counts and does not reproduce the reported values.
- **Normalization:** TMM column sums are computed on the full gene matrix; `voom` and `eBayes` are applied to the full transcriptome, not to the filtered subset.
- **WGCNA:** `blockwiseModules()` in WGCNA 1.74 does not accept several legacy arguments under R 4.6; the pipeline therefore reproduces the same steps manually (MAD top 25%, signed adjacency, power 12, dynamic tree cut, eigengene merge).
- **GSEA:** gene sets are built offline from `org.Hs.egGO2ALLEGS`; of 14,209 annotated sets, 4,697 fall in the 15–500 size range and 3,543 are tested after restriction to the analysed transcriptome. Reported adjusted *P* values are BH-corrected across tested sets.
- **Single-gene GSEA:** ranking ties arise because expression values are discrete; tie fractions are computed from the ranking statistic, not from enrichment scores.
- **Module membership:** genes outside the 6,720-gene network have projected kME values only. The manuscript distinguishes network members from projected genes; the same convention is used in Tables 3 and 5.
- **Independent validation:** GSE74123 has four samples per group. Its processed PCL files (SCAN) were used only to orient probes in the GEO series matrix; the 4/4 comparison uses series-matrix RMA values. No multiplicity adjustment is applied, and the cohort is used as a direction check, not as a second discovery cohort.
